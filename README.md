# 코드 산책

Python 소스 코드의 구조와 함수 호출 관계를 도형과 연결선으로 살펴보는 로컬 코드 뷰어입니다. 파일이나 프로젝트 폴더를 불러오면 클래스, 함수, 변수, import 선언을 분석해 확대·축소 가능한 캔버스에 표시합니다.

코드를 실행하지 않고 Python 표준 라이브러리인 `ast`로 구조를 분석합니다. 복잡한 파일을 클래스와 함수 단위로 펼쳐 보거나, 파일 사이의 함수 호출 관계를 확인하는 데 사용할 수 있습니다.

## 주요 기능

- 여러 Python 파일 또는 프로젝트 폴더 불러오기
- 선언 순서에 따른 코드 구조 표시
- 파일·클래스·함수·변수·import 도형 펼치기와 접기
- 원본 코드와 줄 번호 표시
- 함수 호출 관계를 점선 화살표로 표시
- 같은 파일의 함수 및 다른 파일에서 가져온 함수 연결
- 캔버스 이동, 확대·축소, 도형 드래그
- 우클릭 메뉴로 파일 또는 불러온 폴더 전체를 화면에서 제거

## 화면 구성

| 코드 요소 | 표시 모양 | 클릭 동작 |
| --- | --- | --- |
| 파일 | 모서리가 접힌 문서 | 파일 내부 구조 펼치기·접기 |
| 클래스 | 초록색 원 | 오른쪽에 클래스 멤버 펼치기·접기 |
| 함수·비동기 함수 | 네모 | 오른쪽에 원본 코드 펼치기·접기 |
| 전역변수·클래스 변수 | 노란 육각형 | 선언 코드 펼치기·접기 |
| import | 보라색 둥근 도형 | import 원문 펼치기·접기 |

실선은 코드 구조를 나타내며 실행 순서를 뜻하지 않습니다. 점선 화살표는 호출하는 함수에서 호출 대상 함수로 향합니다.

## 실행 방법

### 준비 사항

- Python 3.9 이상
- 웹 브라우저

앱 실행에는 추가 Python 패키지나 Node.js가 필요하지 않습니다.

### 시작하기

프로젝트 디렉터리에서 다음 명령을 실행합니다.

```bash
python3 viewer.py
```

브라우저가 자동으로 열립니다. 열리지 않으면 터미널에 출력된 로컬 주소로 접속하세요. 서버는 `127.0.0.1`에서 실행되며 사용 가능한 포트를 자동으로 선택합니다.

종료하려면 터미널에서 `Ctrl+C`를 누릅니다.

## 사용 방법

1. 상단 파일 선택 또는 드래그 앤 드롭으로 `.py` 파일을 추가합니다.
2. 프로젝트 단위로 살펴보려면 **폴더 추가**를 사용합니다.
3. 파일 도형을 클릭해 전역변수, 클래스, 독립 함수, import 선언을 확인합니다.
4. 클래스를 클릭하면 소속 함수와 변수가 오른쪽에 나타납니다.
5. 함수 도형을 클릭하면 코드가 열리고, 다시 클릭하면 닫힙니다.
6. 코드 안에서 밑줄이 있는 호출 이름을 클릭하면 대상 함수에 점선이 연결됩니다.

호출 대상을 표시할 때 필요한 파일과 클래스까지만 펼치며 대상 함수의 본문은 자동으로 열지 않습니다. 이미 열어 둔 본문은 유지됩니다. 같은 호출을 다시 클릭하면 점선이 해제됩니다. 연결된 함수나 상위 클래스·파일을 닫아도 관련 호출 연결이 해제됩니다.

### 이동과 확대·축소

- 캔버스 빈 곳 드래그: 화면 이동
- 마우스 휠 또는 하단 `− / ＋`: 확대·축소
- 하단 배율 버튼: 처음 위치와 100% 배율로 복원
- 파일·클래스 도형 드래그: 해당 파일 전체 이동
- 함수·변수·import 도형 드래그: 해당 요소 이동

파일이나 클래스를 닫으면 하위 펼침 상태와 하위 도형의 개별 이동값을 초기화합니다.

### 화면에서 파일 제거

파일 도형을 우클릭하고 **파일을 화면에서 제거**를 선택합니다. 폴더로 불러온 파일은 **폴더 전체를 화면에서 제거**할 수도 있습니다.

이 기능은 캔버스에서만 제거합니다. 디스크의 원본 파일은 삭제하지 않습니다.

## 예제

| 예제 | 확인할 기능 |
| --- | --- |
| `example.py` | 클래스·함수 구조와 비동기 함수 표시 |
| `call_example.py` | 같은 파일의 함수 호출 연결 |
| `project_example/` | import 별칭과 파일 간 호출 연결 |

`call_example.py`에서 `Order → receipt()`를 펼친 뒤 `self.total` 또는 `format_total`을 클릭하면 호출 점선을 볼 수 있습니다.

`project_example` 폴더를 추가한 뒤 `order.py → checkout()`을 펼치세요. `sale`과 `prices.discount`를 클릭하면 `pricing.py`의 `discount()`로 연결됩니다.

## 분석 범위와 제한사항

- Python 파일만 지원하며 파일당 최대 크기는 1 MiB입니다.
- 분석 가능한 문법은 서버를 실행한 Python 버전에 따라 달라집니다.
- 단순한 같은 파일 함수 호출과 일부 `self.메서드()` 호출을 연결합니다.
- 파일 간 호출은 명시적인 절대 import와 별칭을 지원합니다.
- 폴더를 불러오면 상대 경로를 모듈 이름으로 사용합니다. Python import 기준 디렉터리를 선택하세요.
- `.venv`, `venv`, `__pycache__`, `.git` 디렉터리는 폴더 입력에서 제외합니다.
- 상대 import, 외부 패키지, 상속 및 동적 호출의 정확한 해석은 지원하지 않습니다.
- 중첩 함수나 데코레이터 등 일부 구조의 호출 연결은 제한됩니다.
- 동일한 모듈 경로가 여러 개이면 파일 간 연결을 진행하지 않습니다.
- 호출 분석은 정적 분석이므로 실제 실행 시의 호출 대상을 보장하지 않습니다.
- 새로고침하면 불러온 파일과 캔버스 상태가 초기화됩니다.
- 폴더 제거는 선택해서 올린 최상위 폴더 전체를 대상으로 합니다.

## 파일 처리

선택한 소스는 로컬 서버로 전달되어 메모리에서 분석됩니다. 앱은 분석할 파일을 실행하거나 원본 파일을 수정·저장하지 않습니다.

## 프로젝트 구성

```text
.
├── viewer.py           # 로컬 HTTP 서버와 Python AST 분석
├── index.html          # 캔버스 UI, 배치, 연결선, 사용자 조작
├── example.py          # 기본 구조 예제
├── call_example.py     # 같은 파일 호출 예제
├── project_example/    # 파일 간 호출 예제
├── test_viewer.py      # Python 구조 분석 검사
├── test_canvas.cjs     # 캔버스 상태와 이동 로직 검사
└── test_browser.cjs    # 실제 브라우저 통합 검사
```

## 테스트

구조 분석 검사는 추가 패키지 없이 실행할 수 있습니다.

```bash
python3 -m unittest -v
```

Node.js가 설치된 환경에서는 캔버스 로직 검사를 실행할 수 있습니다.

```bash
node test_canvas.cjs
```

브라우저 통합 검사에는 별도로 Playwright와 Chromium이 필요합니다. Playwright가 준비된 환경에서 다음 명령을 실행합니다.

```bash
node test_browser.cjs
```

Playwright가 기본 모듈 경로 밖에 있으면 `PLAYWRIGHT_MODULE`에 모듈 경로를 지정하세요. Chromium 저장 위치를 별도로 설정한 경우 `PLAYWRIGHT_BROWSERS_PATH`도 지정해야 합니다.

브라우저 검사는 로컬 서버를 띄운 뒤 파일·폴더 업로드, 펼치기·접기, 드래그, 확대·축소, 호출 점선, import 표시와 우클릭 제거 기능을 확인합니다. 현재 브라우저 검증은 Chromium 기준입니다.
